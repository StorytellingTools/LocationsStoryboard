# LocationsStoryboard
This program takes images from a folder and compiles them into a video, with each image displayed for one second. Perfect for creating simple slideshows or time-lapse videos, like watching a plant grow.
Create a folder named 'images' and put all your images in them, and an empty folder named 'videos' where you can find the completed video. Put these two folders in the same location as the other files.
Open makevid.py and runmakevid.shell and change the location path to the location path of your files.
To change how long each image appears, open makevid.py and adjust the frame duration.
It includes a simple button app for easy use on macOS. The script also runs directly on Linux.  run Button.desktop from your 'home' directory and it will create a button on your desktop. Right click to 'Allow Launching', then double click the button to run the proogram.
